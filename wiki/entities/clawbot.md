The mechanism model: links, joints, actuators, and what they can reach. Open\*Core-shaped and built to the same rules, though **whether it is a fifth peer is unsettled** — see the note at the end, and [OpenDesignCore#15](https://github.com/thewriterben/OpenDesignCore/issues/15).

**Why not a machine kind inside [[openbuildcore]]** (its ADR-0001), which is the argument worth reading first, because it is about data shape rather than taste. OBC answers "can this part be made" with `envelope_mm` and axis-aligned containment. For a serial mechanism past two joints the reachable set is **non-convex, frequently holed at the base, and can be disconnected across configuration branches** — every box either claims points it cannot reach or disclaims points it can, with no conservative choice available. And a printer's material list does not change when the gantry moves, while an arm's usable payload falls with extension because shoulder torque is force times moment arm. A robot is also on *both* sides of PD-2: a design is shareable reference data, a robot on your bench is owned state, and one partway built is an OBC project.

**Two refusals define it.** There is no `reach_mm` (ADR-0003): a vendor reach figure is a radius to an unstated frame, before a tool, over a sphere joint limits carve holes in — and a citation would prove only that the vendor said it. There is no scalar `payload_kg` (ADR-0004): capacity is derived per-pose from **continuous** actuator torque, never stall, which is the field most datasheets omit. Both are OBC ADR-0005's print-time discipline applied to new quantities.

**A link is a `part_id`, a `make`, or a `provenance_ref`** (ADR-0006), mirroring OBC's three requirement kinds so the vocabularies do not diverge. The third is an ODC `artifact_sha256`. Consuming it exposed a refusal worth knowing about: `manifest.py` **will not turn a `provenance_ref` into an OBC `make` requirement**, because ClawBot stores the hash and never resolves it, so it has no bounding box to declare — inventing a `size_mm` would be a fabricated number inside a document that validates. Those links are reported separately and handed to `can-print --from-sidecar`, which judges the real geometry.

**The representation decision, and what checking it cost.** ADR-0005 chose a URDF-shaped tree over Denavit-Hartenberg parameters, because DH has two live conventions and four columns that do not record which — and, once the sources were read, because a DH table cannot carry the tool transform (it falls out of the factorisation as residue) or branch at all. The ADR then claimed "a converter is a mapping rather than a reinterpretation" **about a converter nobody had written**, which its own inherited-invariants page recorded as a breach of the rule PD-1 paid four hours for. Running it (ADR-0007) found the structure maps and **absence does not**: `urdfdom` refuses a revolute joint with no `<limit>`, so an honest "travel unknown" record has no valid URDF at all; and on import, missing bounds silently become `0` and a missing axis becomes `(1,0,0)`. Export refuses and names the joint; the importer reads the XML rather than the parsed tree, because the parse is where absence is destroyed.

**Derived answers carry their assumptions in the value.** Reachability is sampled and deterministic under a declared seed (ADR-0013), and the asymmetry is deliberate: a sampled set is inner-bounded, so *"reachable"* is a claim carrying the pose that got there and *"not reachable"* is never returned — the verdict is `no-sample-reached-it` with the sample count. Static capacity is the mirror, an upper bound whose **negative** is sound. Compose them (ADR-0015) and **no combination yields a provable yes**, so the affordance verdict is `cannot` / `within-static-bound` / `unproven` / `incomplete`, with **no score** — a float in [0,1] is a frequency estimate, no trials were run, and SayCan-style consumers multiply affordances, so a fabricated one would vanish into a product. Rank on margin, which has units.

**The Rust binding turns refusals into compile errors** (ADR-0017), which is the sharpest thing here. `Radians` and `Degrees` are distinct types, so the seam with [[oh-ben-claw]]'s degrees-taking `ServoAngle` fails to compile rather than failing on the bench. `StallTorque` and `ContinuousTorque` have **no conversion between them** — a consumer wanting the 30-50%-of-stall rule of thumb must write that arithmetic where review sees it. Three `compile_fail` doctests execute those guarantees, which is the only way to test a property that lives in the type system. Zero dependencies, generated and committed with a `--check` staleness gate, per [[openpartscore]] ADR-0003.

Also: assembly records as a DAG with citation-gated fastener torques and no modelled build time (ADR-0011); harness records where **a cable crossing a joint is a joint limit** and `permits_full_travel: null` means nobody checked (ADR-0012); an MCP surface whose propose side is *empty* rather than unused, because the repo has no side effects at all (ADR-0016); and a PD-5 position (ADR-0019) that carries [[project-bingo]]'s taxonomy verbatim, never infers a category from geometry, and refuses to emit a fabrication-bound manifest for an undeclared record because BINGO reads absence as `none` *declared*.

**Three schema defects found by data rather than argument**, all the same shape — a quantity with an operating envelope stored as one number. Torque became voltage-indexed when a real datasheet published three rows spanning 26% (ADR-0014); scalar efficiency was removed when Harmonic Drive's own document showed it varying over five variables (ADR-0018); and starting and backdriving torque were written as ranges from the start, because the variation is unit-to-unit and spans an order of magnitude (ADR-0021). ADR-0018 also introduced `basis` — `model-typical` vs `this-unit` — after a vendor stated in a datasheet that its published stiffness varies ±30% between individual units.

Its `Knowledge/` wiki deliberately matches this one's conventions rather than inventing a second dialect: same three layers, same page types, same index/log split, same grounding rule. Its robotics half was empty on purpose for a day and is now sourced.

**Status:** pre-alpha. Four schemas, 21 ADRs, six stdlib scripts, an MCP surface, a Rust binding; 152 Python and 35 Rust tests, run by CI. `data/` holds **one** real record — a Dynamixel XM430-W350 whose `continuous_torque_nm` is `null` because ROBOTIS names the stall/continuous distinction and then publishes only stall. **No robot record**, because one needs a real mechanism with real datasheets. Apache-2.0. Repo: https://github.com/thewriterben/ClawBot (public).

**Open, and recorded rather than smoothed over:** its own ADR-0001 admits the repo is "justified by a data shape rather than by demand: nothing is asking for it yet." Its README cited this repo's ADR-0007 as making it the fifth peer until 2026-08-22, when it stopped — ADR-0007 enumerates the peers and does not name it, and a citation pointing at a document that does not support it is worse than none. Whether the platform's peer set should grow is a decision nobody has made, and this page describes what exists rather than settling it.
