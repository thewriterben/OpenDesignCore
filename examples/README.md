# Examples

One example must always work end to end. If a change breaks it, the change isn't done.

Each example is self-contained: no network access, no data that isn't in the repo, no manual setup step that isn't in its own README. Every example states the voxel size it runs at and roughly how long it takes at that resolution.

## Structure

```
examples/
  ⟨name⟩/
    README.md    what it demonstrates, voxel size, expected output, runtime
    ⟨inputs⟩
    ⟨run script⟩
```
